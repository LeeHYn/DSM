데일리업 · Phase 1 프로토타입 문서

MVP 인터랙티브 프로토타입 화면 정리 · 2026년 7월 19일

1. 개요

일과 완료 기반 점수·랭킹 습관관리 앱의 Phase 1 MVP 프로토타입입니다. 안드로이드 프레임 안에서 로그인부터 랭킹, 마이페이지까지 전체 사용자 흐름을 인터랙티브하게 확인할 수 있습니다. 다크 모드가 기본값이며, 마이페이지 설정에서 라이트 모드로 전환할 수 있습니다.

2. 화면 구성 (총 8개)

① 로그인

서비스 진입 화면. 소셜 로그인 버튼 제공.

  • Google / Kakao 로그인 (로딩 상태 표시 후 튜토리얼로 이동)
  • Apple 로그인은 준비 중 상태로 비활성 표시
  • 하단 이용약관·개인정보처리방침 링크

② 온보딩 튜토리얼 (3페이지)

최초 로그인 시 노출되는 3단계 소개 화면.

  • 1) 일과 등록과 완료 2) 난이도와 일일 점수 상한 3) 랭킹과 6단계 티어
  • 건너뛰기 가능, 마지막 페이지에서 "시작하기"로 홈 진입

③ 홈 (일과 목록)

당일 일과와 점수 현황을 보여주는 메인 화면. 하단 탭의 첫 번째 탭.

  • 오늘 점수(최대 900점), GOLD 티어 배지, 진행률 바, 누적 점수
  • 일과 리스트: 체크로 완료 처리(낙관적 업데이트 + 실패 시 롤백), 탭하여 상세 진입
  • 우측 하단 FAB(+)로 새 일과 추가
  • 로딩 / 빈 상태 / 오류 / 오프라인 상태 UI 포함

④ 새 일과 추가 (모달)

홈 화면 FAB 또는 빈 상태 버튼으로 진입하는 하단 시트.

  • 제목(필수), 설명, 시작/종료 시간(종료 > 시작 검증), 난이도(낮음/보통/높음), 카테고리 칩 선택, 완료 알림 토글
  • 유효성 오류 인라인 표시 후 저장

⑤ 일과 상세 (모달)

일과 리스트 항목 탭 시 진입하는 하단 시트.

  • 제목/시간/카테고리/난이도/설명 표시
  • 완료 처리·취소, 삭제(확인 단계 포함)

⑥ 랭킹

하단 탭의 두 번째 탭. 일간/주간/누적 랭킹을 확인.

  • 기간 세그먼트 전환(일간/주간/누적)
  • 내 순위 카드(순위·상위 퍼센트·점수), 리더보드 리스트(순위·닉네임·티어·점수)

⑦ 마이페이지

하단 탭의 세 번째 탭. 프로필과 설정 메뉴.

  • 프로필(닉네임·티어 배지·누적 점수)
  • 설정 메뉴: 화면 테마(다크/라이트 토글), 프로필·계정 관리, 알림 설정, 나의 통계, 도움말·규칙·법적 정보(준비 중), 로그아웃

⑧ 하단 탭 내비게이션 · 공통 UI

홈/랭킹/마이 탭 전환은 항상 하단 탭 바에서 이루어지며, 토스트 알림이 모든 화면 공통으로 하단에 표시됩니다.

3. 상태 및 인터랙션

구분내용
로딩스켈레톤 카드/리스트, pulse 애니메이션
빈 상태점선 박스 + 안내 문구 + "새 일과 추가" CTA
오류오류 배너 + "다시 시도" 버튼
오프라인상단 오프라인 배너, 일과 리스트 상호작용 비활성화
일과 완료 처리낙관적 업데이트(즉시 UI 반영) → 실패 시 자동 롤백 + 토스트 안내

하단 개발 도구 바(홈 탭 노출 시)에서 정상/로딩/빈 상태/오류/오프라인 상태를 즉시 전환하며 테스트할 수 있습니다.

4. 디자인 톤

다크 모드 (기본)라이트 모드 게이미피케이션 스타일. 포인트 컬러는 라임 그린(브랜드 액센트), 골드는 티어·랭킹 배지에 사용. 폰트는 Noto Sans KR.
